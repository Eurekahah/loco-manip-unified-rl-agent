# WBC-OmniBench 环境主题任务设计

版本：v0.1  
日期：2026-11-18

## 1. 设计原则

环境主题任务与通用核心任务分离。通用核心任务可以使用 `Simple_Room`，但环境主题任务
必须使用各自对应的场景资产：

- 接待厅主题加载 `Office` 场景资产；
- 医院主题加载 `Hospital` 场景资产；
- 厨房主题使用独立的 `KitchenRoom` 场景资产，不复用 `Simple_Room`；
- 每个主题场景单独制作任务处理资产，包括台面、柜体、病床、托盘、碰撞体和目标区域；
- 任务物体优先使用 YCB，家具和医疗道具优先使用 Isaac 自带资产；
- 所有主题场景继续共享机器人、相机名称、动作空间、HDF5 schema 和评测入口。

**禁止事项**：环境主题任务不得把 `Simple_Room` 作为 `room_scene` 加载，也不得在
`Simple_Room` 中摆放医院或厨房主题道具来伪装成主题场景。

## 2. 主题资产包

### 2.1 接待厅

| 用途 | Isaac 资产 |
|---|---|
| 主接待台 | `Environments/Office/Props/SM_InformationDesk_A.usd` |
| 直线接待台 | `Environments/Office/Props/SM_ReceptionTableStraight.usd` |
| 等候椅 | `Environments/Office/Props/SM_Chair.usd` |
| 沙发 | `Environments/Office/Props/SM_Sofa.usd` |
| 桌面目标 | YCB cracker box、sugar box、mug |

推荐布局：

- 接待台放在房间远侧，台面高度约 `1.0–1.1 m`；
- 目标在接待台内侧或台面边缘；
- 机器人从访客侧接近，托盘放在访客侧矮桌；
- 等候椅和隔离带形成窄通道。

### 2.2 医院

| 用途 | Isaac 资产 |
|---|---|
| 病床 | `Environments/Hospital/Props/SM_HospitalBed_01b.usd` |
| 床头柜 | `Environments/Hospital/Props/SM_BedSideTable_01b.usd` |
| 医疗柜 | `Environments/Hospital/Props/SM_MedicalCabinet_01a.usd` |
| 耗材柜 | `Environments/Hospital/Props/SM_SupplyCabinet_01c.usd` |
| 轮椅障碍 | `Environments/Hospital/Props/SM_WheelChair_01a.usd` |
| 药品/样本代理 | YCB sugar box、mustard bottle、small can |

推荐布局：

- 病床与医疗柜之间留出约 `0.8–1.0 m` 通道；
- 轮椅横放在通道一侧，形成局部窄道；
- 目标在医疗柜或床头柜，目标托盘在病床另一侧；
- 高位医疗柜迫使机器人调整机身高度和 pitch。

### 2.3 厨房

| 用途 | Isaac 资产 |
|---|---|
| 可开合柜体 | `Props/Sektion_Cabinet/sektion_cabinet_instanceable.usd` |
| 台面 | 带 `Oak.mdl` 或 `Parquet_Floor.mdl` 的纹理台面 |
| 金属把手/支架 | `Steel_Stainless.mdl` |
| 目标 | YCB mug、bowl、sugar box、tomato soup can |

推荐布局：

- Sektion 柜体作为低位抽屉和门板来源；
- 台面高度约 `0.85 m`，托盘放在台面内侧；
- 目标可放在抽屉、台面或柜内；
- 通过开关门/抽屉、低姿抓取和台面放置组合成长时程任务。

## 3. 候选任务

### R1 FrontDeskPickup — 接待台取件

任务目的：验证机器人在标准成人工作台高度下，从访客侧完成目标搜索、靠近、抓取和托盘放置。

场景：

- 接待台横放在房间远侧；
- 目标在接待台内侧边缘，访客侧前视相机只能看到部分目标；
- 托盘在访客侧矮桌；
- 等候椅或隔离带形成受限接近路径。

成功判据：

- 目标进入访客侧托盘并稳定 `1.0 s`；
- 接待台上的干扰物未被碰落；
- 机器人未与接待台发生超过阈值的碰撞；
- 90 s 内完成。

关键指标：

- 目标首次进入前视视场的时间；
- 接待台前对准误差；
- 抓取高度误差；
- 台面碰撞次数；
- 成功率。

### H1 WardDelivery — 病房送药

任务目的：验证机器人在病床、医疗柜和轮椅形成的真实窄道中，完成全景搜索、绕障和高低差放置。

场景：

- 医疗柜上放药品代理；
- 病床旁床头柜作为目标放置点；
- 轮椅横放在通道一侧；
- 目标在起始位姿下只被全景相机看到。

成功判据：

- 药品进入床头柜目标区域并稳定 `1.0 s`；
- 轮椅位移小于 `0.05 m`；
- 机器人未摔倒；
- 120 s 内完成。

关键指标：

- 全景到前视的重捕获时间；
- 轮椅附近最小净空；
- 机身高度调整次数；
- 床头柜放置误差；
- 成功率。

### K1 KitchenDrawerServe — 厨房抽屉取放

任务目的：把关节物体操作、低姿抓取和台面放置组合到厨房语境中。

场景：

- Sektion 柜体的中/低层抽屉放置 YCB mug；
- 台面托盘位于柜体右侧；
- 上层柜门部分打开，限制机械臂抬升空间；
- 地面摩擦和抽屉阻尼可随机化。

成功判据：

- 目标抽屉打开超过 `0.15 m`；
- mug 被取出并稳定放在台面托盘；
- 抽屉最终关闭到 `5 cm` 内；
- 120 s 内完成。

关键指标：

- 把手定位误差；
- 抽屉最大开度；
- 机械臂与上层柜门碰撞次数；
- 机身高度/pitch 调整量；
- 成功率。

### H2 SupplyRestock — 医疗柜补货

任务目的：验证高位柜体到低位病床柜之间的连续搬运，并要求机器人主动改变机身高度。

场景：

- 目标从医疗柜中层取出；
- 目标容器在床头柜或地面托盘；
- 医疗柜前方有轮椅或推车形成接近约束；
- 允许一次重抓取。

成功判据：

- 目标进入床头柜区域并稳定 `1.0 s`；
- 医疗柜未倾倒；
- 机器人未摔倒；
- 150 s 内完成。

关键指标：

- 最高抓取高度；
- 机身升降次数；
- 机械臂伸展时底盘后退量；
- 重抓取次数；
- 成功率。

## 4. 与现有任务的关系

- P1 RearPick 可直接作为 R1 的后侧搜索变体；
- W1 DrawerLadder 可作为 K1 的抽屉技能来源；
- W2 DoorBrace 可复用医院病房门或厨房推拉门；
- W5 HighLowServe 可作为 H2 的高低位技能来源；
- L1 HomeMission 可组合 R1、H1、K1 中的子目标形成长时程任务。

## 5. 实施顺序

1. 建立三个独立主题场景：`Office` 接待厅、`Hospital` 病房、`KitchenRoom` 厨房；
2. 在每个主题场景资产中分别制作接待台、病床/医疗柜、橱柜/台面等任务处理资产；
3. 为每类道具补充缩放、朝向、碰撞和可放置区域；
4. 先实现 R1 和 H1，验证标准台面高度与窄道操作；
5. 再实现 K1，接入 Sektion 抽屉和门关节；
6. 最后将 H2 与 L1 组合，加入重抓取和恢复逻辑；
7. 所有任务共用前视相机 `x=0.58 m, z=0.12 m` 和近/远裁剪
   `(0.001 m, 1.0e9 m)` 的安装约定。

## 6. 验收标准

- 主题任务不得加载 `Simple_Room`；
- 接待厅、医院、厨房任务分别加载 `Office`、`Hospital` 和 `KitchenRoom`；
- 每个主题场景包含自己的任务处理资产和可放置区域；
- 主题道具不覆盖机器人出生点和主要相机视线；
- 地板、墙面、天花板和主要家具均有纹理材质；
- 前视相机下缘不出现机器人自身轮廓；
- 质量渲染截图中不出现默认黑色地面网格；
- 主题资产缺失时给出明确错误，不静默回退到灰色 primitive 场景。
